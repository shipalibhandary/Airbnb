## 🏡 Airbnb-Style Property Listing
A responsive Airbnb-inspired property listing website built with React + Vite. The project features a clean property grid, interactive property detail modal, responsive layouts, and smooth user interactions using static data.

## 🌐 Live Demo
[View Live Demo](https://airbnb-seven-bice.vercel.app/)

## ✨ Features
- Responsive property listing grid
- Property cards with images, location, price, and ratings
- Search-style header UI
- Interactive property detail modal
- Multiple property images inside the modal
- Fully responsive design for desktop, tablet, and mobile

## 🛠️ Tech Stack
### Frontend
- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- Tailwind CSS
